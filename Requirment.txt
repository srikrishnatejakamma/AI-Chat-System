Building a fully local RAG (Retrieval-Augmented Generation) system on your personal laptop requires an organized blueprint. This structured execution plan breaks down the architecture, folder setup, multi-file Python codebase, and local vector engine into manageable steps.

Step 1: Directory & Environment Setup
Create a dedicated folder for your application structure to keep your data, vector database, and source code cleanly organized.

Open your terminal and run:

Bash
mkdir local-ai-chat
cd local-ai-chat
python -m venv venv
Activate your virtual environment:

Windows: venv\Scripts\activate

Mac/Linux: source venv/bin/activate

Install the essential offline stack libraries:

Bash
pip install langchain langchain-ollama langchain-chroma langchain-community pypdf python-docx sentence-transformers streamlit
Step 2: Download Your Local AI Engines
Before running code, make sure Ollama is active on your laptop and has downloaded the required model weights:   
neurohive.io

For General Chat & Generation: ollama run llama3.1:8b (or phi3 if your laptop has lower RAM)

For High-Performance Embeddings: ollama run nomic-embed-text (crucial for accurate local vector mapping)

Step 3: Modular Application Code Structure
Instead of putting everything in a single massive file, split your application into two clean files: an ingestion script to process documents and a web UI application for interactive chatting.

1. Create ingest.py (Handles Document Upload & Indexing)
This script parses uploaded PDF/TXT/DOCX files, chops them into small fragments, computes local numerical embeddings, and saves them to a permanent offline database (chroma_db).

Python
import os
from langchain_community.document_loaders import PyPDFLoader, Docx2txtLoader, TextLoader
from langchain_text_splitters import RecursiveCharacterTextSplitter
from langchain_ollama import OllamaEmbeddings
from langchain_chroma import Chroma

DB_DIR = "./chroma_db"
EMBEDDING_MODEL = "nomic-embed-text"

def process_and_store_document(file_path):
    ext = os.path.splitext(file_path)[1].lower()
    
    # Select appropriate document parser loader
    if ext == ".pdf":
        loader = PyPDFLoader(file_path)
    elif ext == ".docx":
        loader = Docx2txtLoader(file_path)
    elif ext == ".txt":
        loader = TextLoader(file_path, encoding="utf-8")
    else:
        raise ValueError("Unsupported file format! Use PDF, DOCX, or TXT.")
    
    docs = loader.load()
    
    # Split text into bite-sized semantic blocks
    text_splitter = RecursiveCharacterTextSplitter(chunk_size=800, chunk_overlap=100)
    chunks = text_splitter.split_documents(docs)
    
    # Save embeddings to local disk vector storage
    embeddings = OllamaEmbeddings(model=EMBEDDING_MODEL)
    vector_store = Chroma.from_documents(
        documents=chunks,
        embedding=embeddings,
        persist_directory=DB_DIR
    )
    print(f"Successfully vectorized and indexed: {file_path}")
    return True
2. Create app.py (The Web UI Chat Interface)
Using Streamlit, this file creates a clean browser-based GUI locally on your laptop where you can upload documents and chat with them in real time.

Python
import os
import streamlit as st
from langchain_ollama import ChatOllama, OllamaEmbeddings
from langchain_chroma import Chroma
from langchain_core.prompts import ChatPromptTemplate
from langchain_core.output_parsers import StrOutputParser
from langchain_core.runnables import RunnablePassthrough
from ingest import process_and_store_document

DB_DIR = "./chroma_db"
LLM_MODEL = "llama3.1:8b"
EMBEDDING_MODEL = "nomic-embed-text"

st.set_page_config(page_title="Local AI Document Chat", layout="centered")
st.title("📁 Private Local Document Chat")
st.write("100% Offline, Private AI Chat running entirely on your laptop with zero cloud APIs.")

# --- Sidebar: Document Uploader ---
with st.sidebar:
    st.header("Document Ingestion")
    uploaded_file = st.file_uploader("Upload a PDF, TXT, or DOCX", type=["pdf", "txt", "docx"])
    
    if uploaded_file is not None:
        os.makedirs("./temp", exist_ok=True)
        temp_path = os.path.join("./temp", uploaded_file.name)
        with open(temp_path, "wb") as f:
            f.write(uploaded_file.getbuffer())
        
        if st.button("Process Document"):
            with st.spinner("Processing and chunking document locally..."):
                try:
                    process_and_store_document(temp_path)
                    st.success("Document indexed successfully!")
                except Exception as e:
                    st.error(f"Error processing file: {e}")

# --- Main Chat Interface ---
if os.path.exists(DB_DIR) and os.listdir(DB_DIR):
    embeddings = OllamaEmbeddings(model=EMBEDDING_MODEL)
    vector_store = Chroma(persist_directory=DB_DIR, embedding_function=embeddings)
    retriever = vector_store.as_retriever(search_kwargs={"k": 3})
    
    llm = ChatOllama(model=LLM_MODEL, temperature=0.3)
    
    template = """You are a precise, helpful assistant. Answer the question using ONLY the context provided below. 
If the answer cannot be found in the context, explicitly state: "I cannot find this information in the uploaded document."

Context:
{context}

Question: {question}
Answer:"""
    
    prompt = ChatPromptTemplate.from_template(template)
    
    def format_docs(docs):
        return "\n\n".join(doc.page_content for doc in docs)
        
    rag_chain = (
        {"context": retriever | format_docs, "question": RunnablePassthrough()}
        | prompt
        | llm
        | StrOutputParser()
    )

    # Initialize chat history state
    if "messages" not in st.session_state:
        st.session_state.messages = []

    for message in st.session_state.messages:
        with st.chat_message(message["role"]):
            st.markdown(message["content"])

    if user_query := st.chat_input("Ask a question about your document..."):
        st.session_state.messages.append({"role": "user", "content": user_query})
        with st.chat_message("user"):
            st.markdown(user_query)

        with st.chat_message("assistant"):
            with st.spinner("Thinking locally..."):
                response = rag_chain.invoke(user_query)
                st.markdown(response)
                st.session_state.messages.append({"role": "assistant", "content": response})
else:
    st.info("👈 Please upload and process a document using the sidebar to begin chatting.")
Step 4: How to Launch and Test Your System
Open your terminal inside your project directory with your virtual environment active.

Run the Streamlit web application command:

Bash
streamlit run app.py
Your web browser will automatically launch a local webpage (http://localhost:8501).

Upload a file (like a company policy PDF, a school textbook, or notes), click Process Document, and begin asking questions instantly—fully disconnected from the internet.
